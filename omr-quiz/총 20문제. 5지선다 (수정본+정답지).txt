총 20문제. 5지선다. (답은 1~5 중 하나)
※ 오름차순/내림차순은 같은 값 없이 점점 커지거나/작아지는 것을 말한다.
※ ( ) 로 묶은 명제 = 모순이 생겨 삭제·교체해야 하는 명제

P01  1번과 2번 답의 합은 7이다.
P02  1~5번 문제의 답에는 3번이 없다.
P03  3~5번 문제의 답은 내림차순이다.
P04  5의 배수 문제 중 답이 5번인 것이 3개이다.
P05  6~8번 문제의 답은 내림차순이다.

P06  (6~10번 문제 중 답이 3인 것이 2개이다.)
P07  9번 문제 답은 5이다.
P08  (11~15번 문제 중에는 중복되는 답이 없다.)
P09  4의 배수 문제는 답이 4가 아니다.
P10  홀수 번호 문제의 답은 홀수이다.

P11  16~20번 문제의 답은 소수이다.
P12  (15번과 16번 답의 합은 6이다.)
P13  (6의 배수 문제의 답은 오름차순이다.)
P14  17번 문제의 답은 3이다.
P15  7번, 12번, 17번 문제는 답이 같다.

P16  3번, 6번, 9번 문제는 답이 같다.
P17  11번 15번 문제의 답의 합은 6이다.
P18  (12~14번 문제의 답은 오름차순이다.)
P19  13~15번 문제의 답은 모두 서로소이다.
P20  13~15번 문제 답의 합은 10이다.
P21  (14번 문제의 답은 2이다.)


[왜 삭제해야 하나]
P06  9번=5 → 3·6번=5 → 5번=1이 되어 10번=5. 6~8번 내림차순(5>3>?)이면 8번<3 → 6~10번에 3은 7번 하나뿐.
P08  13번+15번=8(P20·P21)이고 둘 다 홀수 → 3과 5. 그런데 12번이 이미 3 → 중복 발생.
P12  15번=5(P04)이면 16번=1 → 16번은 소수(P11)여야 해서 모순.
P13  6번=5, 12번=3 → 6→12→18 오름차순 불가.
P18  12번=3, 14번=2 → 3 < 13번 < 2 불가.
P21  P18을 바꾸면 14번은 P20만으로 2가 결정되어, 그대로 두면 19번 답을 정할 명제가 없음(19번이 3/5 두 가지).


[교체 제안]  ← 마음에 드는 것만 채택하세요
P06  →  6~10번 문제 답의 합은 20이다.
P08  →  11~15번 문제 중 답이 3인 것은 2개이다.
P12  →  15번과 16번 답의 합은 8이다.
P13  →  6의 배수 문제의 답은 내림차순이다.
P18  →  12번과 13번 문제는 답이 같다.
P21  →  14번과 19번 답의 합은 7이다.
