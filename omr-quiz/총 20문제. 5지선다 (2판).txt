총 20문제. 5지선다. (답은 1~5 중 하나) — 2판
아래 명제가 모두 참이 되도록 1~20번 문제의 정답을 찾아라.
※ 오름차순/내림차순은 같은 값 없이 점점 커지거나/작아지는 것을 말한다.
※ ☆ = 덜 중요한 명제. 빼도 정답이 하나로 정해진다.

Q01    1번과 2번 답의 합은 4이다.
Q02    1~5번 문제의 답에는 2번이 없다.
Q03    3~5번 문제의 답은 오름차순이다.
Q04    5의 배수 문제 중 답이 5번인 것이 2개이다.
Q05    6~8번 문제의 답은 모두 다르다.

Q06    6~10번 문제 답의 합은 20이다.
Q07    19번 문제 답은 2이다.
Q08 ☆ 11~15번 문제 중 답이 5인 것은 2개이다.
Q09    4의 배수 문제는 답이 2가 아니다.
Q10 ☆ 홀수 번호 문제의 답에는 3이 없다.

Q11    16~20번 문제의 답은 모두 다르다.
Q12    15번과 16번 답의 합은 8이다.
Q13    6의 배수 문제의 답은 모두 같다.
Q14 ☆ 17번 문제의 답은 1이다.
Q15    7번, 12번, 17번 문제의 답은 내림차순이다.

Q16    3번, 6번, 9번 문제의 답은 오름차순이다.
Q17    11번 15번 문제의 답의 합은 7이다.
Q18 ☆ 13번 답은 12번 답보다 크다.
Q19 ☆ 13~15번 문제의 답 중 짝수는 1개뿐이다.
Q20    13~15번 문제 답의 합은 12이다.

Q21    14번과 19번 답의 합은 4이다.
Q22 ☆ 15번 문제 답은 5이다.
Q23 ☆ 6~10번 문제의 답에는 1이 없다.
Q24    2번 문제 답은 3이다.



────────────── 여기서부터 출제자용 ──────────────

[짝 명제]  두 문제의 합 ↔ 그중 한 문제의 답 — 짝끼리 합치면 두 칸이 바로 풀린다
  Q01 1번+2번=4   ↔ Q24 2번=3            → 1번=1
  Q21 14번+19번=4 ↔ Q07 19번=2           → 14번=2
  Q12 15번+16번=8 ↔ Q22 15번=5 ↔ Q17 11번+15번=7  → 16번=3, 11번=2  (15번이 세 명을 잇는 허브)

[학생 수에 따라 빼는 순서]  ☆는 어떤 조합으로 빼도 정답이 유일 (★ 17개만으로 유일)
  23명: Q19   22명: +Q08   21명: +Q23   20명: +Q18
  19명: +Q10  18명: +Q14   17명: +Q22
※ Q22는 짝 명제의 허브라 마지막에 뺀다. 빠져도 Q12·Q17을 가진 두 사람이 15번을 공유해 협력 가능.

[풀이]  (☆ 없이 ★ 17개만 사용)
1) 짝: Q07 19번=2 → Q21 14번=2.  Q24 2번=3 → Q01 1번=1
2) Q20 13번+15번=10 → 둘 다 5.  Q12 16번=3, Q17 11번=2
3) Q11 16~20번 모두 다름: 16번=3, 19번=2 → 17·18·20번 ∈ {1,4,5}
4) Q13 6번=12번=18번, Q15 7번>12번>17번 → 12번은 1도 5도 아님 → 6·12·18번=4, 7번=5, 17번=1, 20번=5
5) Q16 3번<4<9번 → 9번=5.  Q04 5의 배수 중 5는 15·20번 → 5번≠5
6) Q03 3<4<5번, Q02(2 없음) → 3번=1, 4번=3, 5번=4
7) Q06 6~10번 합 20 → 8번+10번=6. Q05·Q09 8번∉{4,5,2}, 10번≠5 → 8번=3, 10번=3

[1판과 바꾼 점]  세트는 유지, 술어·숫자만 교체
  1~5번 3 없음 → 2 없음          3~5번 내림차순 → 오름차순
  6~8번 내림차순 → 모두 다름      홀수 번호 답은 홀수 → 홀수 번호 답에 3 없음(약화)
  16~20번 소수 → 모두 다름        6의 배수 내림차순 → 모두 같음
  7·12·17 같음 → 내림차순         3·6·9 같음 → 오름차순
  12·13번 같음 → 13번>12번        13~15 서로소 → 짝수 1개뿐
  전체 4 없음 → 6~10번에 1 없음(범위 축소)
  9번=5(1판과 동일) → 19번=2      전체 합 → 15번=5      답 1이 2개 → 2번=3   (짝 명제화)
