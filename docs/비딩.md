# 돌림판 비딩

기댓값이 다른 룰렛을 경매로 사 모은다. 쇼기 대회·한글 퀴즈와 같은 관리자
화면에서 열고, 학생은 `bid.html` 로 들어온다. 서버도 닉네임도 같은 것을 쓴다.

조마다 **대표 한 명만** 값을 부른다. 나머지는 관전이다. 실제 상의는 화면
밖에서 시끄럽게 벌어질 것이고, 그게 이 수업의 알맹이다. 화면은 값을 받아
적고 시간을 재는 일만 한다.

## 룰렛 스물넷

칸은 셋, 확률은 고르다(각 1/3). 칸 값은 **10단위**다. 기댓값은 소수 둘째
자리까지 적어 **처음부터 다 보여 준다** — 숨겨서 맞히는 놀이가 아니라, 알고도
얼마를 지를지 다투는 놀이다.

무작위로 뽑지 않고 손으로 짰다. **같은 기댓값에 분산만 다른 짝**을 일부러
여럿 넣었다.

| 기댓값 | 짝 |
|---|---|
| 13.33 | `10,10,20` · `-10,20,30` · `-10,-10,60` |
| 10.00 | `10,10,10` · `-10,-10,50` |
| 20.00 | `20,20,20` · `-20,40,40` |
| 23.33 | `10,20,40` · `-30,30,70` |
| 30.00 | `30,30,30` · `-50,40,100` |
| 50.00 | `50,50,50` · `-30,50,130` |
| 70.00 | `70,70,70` · `20,70,120` |
| 100.00 | `100,100,100` · `0,100,200` |
| -10.00 | `-10,-10,-10` · `-30,-10,10` |
| -40.00 | `-40,-40,-40` · `-100,-20,0` |

「어느 쪽이 비싼가」가 아니라 「같은 값인데 왜 느낌이 다른가」를 놓고 다투게
하려는 것이다.

받기 싫은 룰렛(기댓값이 음수)은 다섯이다.

## 한 판의 모양

**작전타임 3분 → 경매 여섯.** 그것을 세 번 돌면 **열여덟 품목**이 끝난다.
쉼 없이 열여덟을 내리 부치면 조가 상의할 틈이 없다. 작전타임은 관리자가
언제든 끊을 수 있고, 길이도 열 때 정한다.

스물넷 중 **열여덟만** 나온다. 무엇이 안 나올지는 아무도 모른다. 그래서
「저건 나중에 사면 되지」가 통하지 않는다.

`경매 현황` 버튼을 누르면 스물넷이 통째로 뜬다. 끝난 것 / 지금 걸린 것 /
아직인 것이 표시되고, 끝난 것에는 누가 얼마에 가져갔는지가 붙는다.

## 값 부르기

**선(先)이 없다.** 모두가 같은 순간에 부른다. 서버에 먼저 닿은 것이 먼저다.

| | |
|---|---|
| 토큰 | 팀마다 **30개**로 시작 |
| 증분 | 늘 **마지막 값보다 1 이상** 높게 |
| 시간 | 품목당 1분 (10~120초로 열 수 있다) |
| 연장 | 막판 호가에는 **10초**를 되돌려 준다. 다만 한 품목 3분을 넘기지 않는다 |
| 낙찰 | 시간이 다할 때 마지막으로 부른 팀. **그때 토큰이 빠진다** |
| 유찰 | 아무도 안 부르면 아무도 못 가져간다 |

마지막 1초를 노리는 것이 이기는 수가 되면 경매가 아니라 반사신경 겨루기가
된다. 그래서 연장이 있다.

## 받기 싫은 룰렛 — 탈출 경매

토큰을 내고 **빠진다**. 빠지는 값도 마지막 값보다 1 이상 높아야 하므로
늦게 빠질수록 비싸다.

- 마지막 한 팀은 빠질 수 없다. 그 팀이 **토큰을 한 개도 안 쓰고** 룰렛을 받는다.
- 빠진 팀이 낸 토큰은 **그대로 사라진다**. 누구에게도 가지 않는다.
- 토큰이 모자라면 빠질 수 없다. 빈털터리가 받는다.
- 시간이 다했는데 둘 이상 남아 있으면 **토큰이 가장 넉넉한 팀**이 받는다
  (동률이면 무작위). 아무도 안 움직여 판이 멎는 일이 없게 하는 장치다.

## 점수

**남은 토큰은 점수가 아니다.** 아껴 봐야 종이다. 끝까지 뜨겁게 쓰라는 뜻이고,
토큰 30개는 「얼마를 쓸까」가 아니라 「무엇에 쓸까」를 고르는 자원이다.

비딩이 끝나면 돌린다. 모든 팀의 **1번 룰렛을 한꺼번에**, 5초. 멎으면 그 값이
점수에 더해지고 **순위판이 미끄러져 움직인다**. 그다음 2번 룰렛, 또 한꺼번에.
이것을 가장 많이 가진 팀의 개수만큼 되풀이한다.

혼자 돌리면 자기 운만 보이고, 같이 돌려야 남의 운이 보인다.

최종 점수는 **실제로 멈춘 칸의 합**이다. 기댓값이 아니다 — 그 어긋남을 눈으로
보는 것이 이 수업의 끝이다.

## 파일

```
server/wheels.js   룰렛 스물넷. 손으로 짠 표다
server/bid.js      경매·토큰·점수. 소켓도 DB 도 모른다
server/bid.test.js 모델 검사
server/bidws.test.js 소켓 왕복 검사
docs/design/bid.template.html → bid.html   학생·대표 화면
```

관리자 화면(`admin.html`)에 대회·퀴즈와 나란히 붙는다. 비번은 쇼기 대회와
같은 것(`.env` 의 `ADMIN_PW` 또는 하드코드 해시)을 쓴다.

```
cd docs/design && python build.py bid ../../bid.html
cd server && npm test
```
