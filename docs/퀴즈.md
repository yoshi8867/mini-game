# 한글 퀴즈

찢긴 글자를 팀으로 맞힌다. 쇼기 대회와 같은 관리자 화면에서 열고, 학생은
`quiz.html` 로 들어온다. 서버도 같은 것을 쓴다 — Render 무료 인스턴스는
한 워크스페이스에 하나만 올리는 편이 좋아서, 둘을 따로 띄우지 않았다.

## 무엇이 뜨는가

글자를 14x14 **점판**으로 굳혀 두고, 켜진 칸을 셋으로 나눠 **한 장씩만**
보여 준다. 4초마다 다음 장으로 넘어가고, 셋을 다 돌면 처음 장으로 돌아온다.
머릿속에서 세 장을 겹쳐야 글자가 선다.

점을 하나씩 흩지 않는다. 돋움 14px 의 획은 한두 칸 두께라 낱낱이 흩으면
글자가 아니라 먼지가 된다. 붙어 있는 점 셋을 한 덩어리로 묶고 덩어리째
나눠 줘야 낱장에 획 토막이 남는다.

가르기는 낱말 **통째로** 한다. 글자마다 따로 가르면 글자마다 꼭 1/3 씩
떨어져 고르고 심심해진다. 통째로 가르면 어느 장에서는 첫 글자가 텅 비고
넷째 글자가 꽉 찬다 — 세 장을 다 봐야 한다.

글꼴은 아무도 모른다. 점판으로 굳혀 두었으므로 학생 폰에 돋움이 깔려
있든 말든 같은 그림이 뜬다.

## 팀

| | |
|---|---|
| 인원 | 19~24명을 본다. **3명이 한 팀**, 남으면 4명인 팀이 생긴다 |
| 최소 | 셋은 반드시 채운다. 여섯은 있어야 두 팀이 되고, 그래야 시작한다 |
| 배정 | 무작위. 관리자가 **시작을 누르는 순간** 참가가 마감되고 팀이 굳는다 |
| 이름 | 사람은 닉네임(앞말+뒷말), 팀은 동물 하나 — 「수달팀」 |

24명이면 셋씩 여덟 팀, 19명이면 넷 하나와 셋 다섯 — 순위판이 6~8줄이다.

## 점수

**점수는 시간이다.** 문제가 뜬 뒤 흐른 초를 그대로 받는다. 늦게 맞힐수록
많이 받는다 — 빨리 맞히는 경쟁이 아니라, 아무도 못 맞히는 문제가 비싸지는
판이다. mm:ss 로 적는다.

| | |
|---|---|
| 득점 | 문제가 뜬 뒤 흐른 초. 다만 **글자 수 × 1분**까지만 |
| 실점 | 오답은 **고정 20초**. 곱도 없다 |
| 4인팀 | 득점에 **3/4** 를 곱한다. 머리가 하나 더 있으니 그만큼 뗀다 |
| 만점 | 그 문제의 최고점을 받는 경우에는 **곱하지 않는다** |
| 같은 오답 | 두 번 내도 한 번만 깎는다 — 손이 미끄러진 것으로 두 번 벌하지 않는다 |
| 바닥 | 없다. 음수로 내려간다. 0 에서 멈추면 오답이 공짜가 된다 |

4인팀의 곱은 **배정될 때 4인이었는지**로 굳는다. 도중에 사람이 빠졌다고
곱이 풀리지는 않는다 — 그러지 않으면 한 명이 나가 버리는 것이 이득이 된다.

## 한 문제가 흘러가는 모양

1. 낱장 한 장이 뜬다. 4초마다 다음 장
2. 누구든 답을 친다. 틀리면 그 사람 화면만 붉어지고 팀 점수가 20초 깎인다
3. **한 명이라도 맞히면** 그 팀이 득점하고 정답을 공개한다
4. 공개 — 성한 글씨를 **붉게** 2초 세운다. 그 뒤로도 붉은 글씨는 그대로
   깔아 두고, 그 위에 **낱장 하나씩만 검게** 덮어 0.5초마다 갈아 끼운다
   (5초). 붉은 바탕이 성한 글자고 검은 토막이 내가 보던 한 장이다 —
   내가 본 것이 글자의 어디였는지 그 자리에서 보인다
5. **맞힌 사람 닉네임**이 가장 크게 뜨고, 그 팀 닉네임이 모두 뜨고, 획득
   점수가 뱃지로, 순위가 바뀌었으면 「6위 → 3위」가 큰 글씨로 뜬다
6. 다음 문제

닉네임마다 **금 뱃지**(맞힌 횟수)와 **붉은 뱃지**(틀린 횟수)가 붙는다.
순위판에도 똑같이 붙는다. 횟수만 적는다 — 몇 초를 벌고 잃었는지는 팀
점수가 이미 말하고 있다.

**남은 문제 수는 안 알려 준다.** 몇 번째인지만 뜬다. 마지막 문제가
「끝」이라서, 그것을 맞히는 순간 끝난 줄 알게 된다. 그것 자체도 문제다.

아무도 못 맞히는 문제는 관리자가 **넘긴다**. 최고점에 닿으면 더 기다릴
까닭이 없는데, 그 판단은 교실에 선 사람이 한다. 넘긴 문제도 공개는 똑같이
한다 — 끝내 모르면 그 몇 분이 배움으로 남지 않는다.

## 어디서 못 보게 막았는가

* **답은 서버만 안다.** 맞히기 전까지 아예 안 내려간다
* **낱장도 지금 것 한 장만** 내려간다. 셋을 한꺼번에 주면 소스를 열어
  겹치면 그만이라 기다릴 까닭이 없어진다
* 채점도 서버가 한다. 페이지에서 하면 소스를 열어 건너뛴다

그래서 `glyphs.js` 와 `dots.js` 는 `shared/` 가 아니라 `server/` 에 있다.

## 문제 고치기

`docs/문제.txt` 를 고치고 다시 찍는다.

```bash
python tools/glyphs.py      # docs/문제.txt → server/glyphs.js
node server/dots.test.js    # 점판과 가르기
node server/quiz.test.js    # 팀·점수·순위
```

찍는 데만 Pillow 와 돋움(`gulim.ttc`)이 든다. 찍혀 나온 `glyphs.js` 는
아무것도 안 든다. 1~4글자만 낼 수 있고, 14x14 에 안 들어가는 글자가 있으면
`tools/glyphs.py` 가 거기서 멈춘다.
