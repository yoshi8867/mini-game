# 타자 올림픽

한글 타자와 문서 편집 단축키를 반 전체가 겨루며 익힌다. 여섯 팀이 네 종목을
치르고 메달을 모은다. 다른 대회 게임처럼 서버가 판정하고, 교사가 진행한다.

| 화면 | 누가 |
|---|---|
| `typing.html?t=1` | 교사 — 로그인, 대회 열기, 진행 버튼. 교실 앞에 띄운다 |
| `typing.html` | 학생 |

규칙을 맞춰 본 실험실(`olympics-lab.html`)과 문제 도구(`words-tool.html`,
`quotes-tool.html`)는 로컬에만 있다. 도구가 저장하는 파일은
`server/typing-words.js`, `server/typing-quotes.js` 다.

## 흐름

1. **팀 고르기** — 학생이 2×3 칸 중 하나에 들어간다. 교사가 마감하면 안 고른
   사람은 가장 적은 팀으로 간다. 교사가 이름을 끌어다 옮긴다. **여섯 팀이 다
   차야 시작한다.** 2~4종목 대진은 판마다 그때 짠다.
2. 종목마다 **소개 → 경기 → 종목 결과(1분)**. 네 종목이 끝나면 **종합 발표**.

| 종목 | 방식 | 메달 |
|---|---|---|
| 1. 단어 개인전 | 학생이 어휘(조)를 고른다. 60초 한 판 × 두 게임, 게임마다 조를 새로 고른다 | 게임마다 조별 금은동 (개인 → 그 팀) |
| 2. 문장 팀전 | 팀 대 팀, 인용문 6개, 150초 × 두 판 | 승점 1·2·3위 팀 |
| 3. 문장 편집 팀전 | 팀 대 팀, 문장(두 팀 인원 × 1.5)을 고쳐 Enter, 90초 × 두 판 | 같음 |
| 4. 표 편집 팀전 | 팀 대 팀, 각자 회계 표를 정답 표처럼 고친다, 90초 × 두 판 | 같음 |

## 정한 것

| 항목 | 결정 |
|---|---|
| 시간제 | 모든 경기. 끝난 문제 자리에 새 문제가 들어와 바닥나지 않는다 |
| 배점 | 짧음·중간·긺 10·20·30. **후반(절반 뒤)에 새로 나오는 문제는 30·40·50** |
| 1종목 조 | 음식 · 고사성어 · 도시 · 가을. **3명 이하인 조는 없애고** 그 사람들은 남은 조로 흩는다 |
| 1종목 순위 | 점수 → 맞힌 단어 수 → 타수 |
| 입력 | 치기 시작하면 맞는 항목을 찾는다. 오타는 지우지 않는다 — 고치거나 Enter 로 비운다. 남이 먼저 치면(마감) 비운다. 영문 입력은 막고 알린다 |
| 판정 | 서버. 친 글자가 문제와 똑같아야 하고 먼저 온 쪽이 갖는다. 4종목만은 각자 화면에서 고치므로 다 고쳤다는 알림을 믿는다 |
| 대진 | 판마다 짠다. **1번** — 같은 종목에서 만난 팀, 바로 앞 판에서 만난 팀과는 다시 붙지 않는다(종목이 바뀌면 그 한 판만 본다). **2번** — 그 안에서 실력이 비슷한 팀끼리(두 팀 차이의 합이 가장 작게). 실력은 그 종목 팀 점수, 종목 첫 판이면 앞 종목 순위. 예: 첫 판 1-2·3-4·5-6, 점수 200·100·220·160·140·120 → 1-3·2-6·4-5 |
| 3·4종목 마우스 | 키보드로만 고친다. 입력 칸 위에 투명한 덮개(커서 🚫)를 씌워 클릭이 닿지 않는다. 막힌 클릭이 나오면 포커스·커서를 그대로 두고 「방향키 또는 Tab으로 조작해 보세요」(4종목)·「Ctrl + 방향키를 이용해 보세요」(3종목). 끌거나 두 번 눌러 고르면 「Ctrl+A로 전체 선택 해 보세요」·「Ctrl + Shift + 방향키로 선택해 보세요」. 오른쪽 클릭 메뉴도 막는다. 손가락만 있는 기기(휴대폰)에는 씌우지 않는다 |
| 미리 보기 | 판마다 15초. 맞대결 팀과 팀원 타수·메달, 「경기가 N초 후에 시작됩니다」 |
| 판 결과 | 같은 카드에 승패, 팀원 득점·맞힌 수, MVP 한 명 👑 |
| ×2 | 지고 있는 팀의 가장 약한 학생(1종목 타수)에게만, 새 문제 셋 중 하나꼴. 그 학생에게만 보인다 |
| 인원 보정 | 적은 팀은 비례 가점 (3명 대 4명이면 ×4/3) |
| 리그 순위 | 승 2 · 무 1, 같으면 득점 |
| 3종목 | 고칠 곳 2·3·4곳 → 10·20·30점. 바뀌는 두 말은 받침 유무를 맞춰 조사가 어긋나지 않게 |
| 4종목 과제 | 모델명 고치기·비고 고치기·비고 옮기기·비고 지우기 10 / 금액 열 0으로·행 지우기 20 / 빈 행으로 행 옮기기 30. 고치기는 다른 부분만 노랗게 |
| 3·4종목 소개 | 규칙 대신 **단축키 안내를 크게**, 그 밑에 연습 칸 |
| 종목 결과 | 팀 순위·이번 메달·누적 메달, 우리 팀 득점표와 MVP 셋(누적 메달 포함). 1분 뒤 저절로 넘어간다 |
| 종합 | 금 → 은 → 동 메달 수. 종목별 팀 순위와 메달리스트 |

## 리허설

교사 화면의 팀 고르기에서 **+6명**을 누르면 연습 참가자가 들어온다. 아무
팀에나 들어가고, 경기에서는 사람처럼 시간을 들여 친다. 혼자서도 끝까지 돌려
볼 수 있다.
