# 블라인드 — OMR 명제 퀴즈

20문제 5지선다인데 **문제 지문이 없다.** 정답 배열 자체가 퍼즐이고, 학생은
그 배열에 관한 **명제 한 줄**만 받는다. 서로 거래하고 속이며 스무 칸을 채운다.

- 심판: `server/omr.js` · 명제와 정답: `server/props.js`
- 틀: `docs/design/omr.template.html` → `python docs/design/build.py omr ../../omr.html`
- 만든 과정과 설계 원칙: [`omr-quiz/README.md`](../omr-quiz/README.md)
- 기획: `플레이 화면(교사용공개용).txt` · 그림: 실제 OMR 답안지 사진

## 세 화면

| | | |
|---|---|---|
| 관리자 | `admin.html` | 대회·퀴즈·비딩과 같은 자리에서 열고, 시작하고, 닫는다 |
| 교실 앞 | `omr.html?t=1` | 시간 게이지와 진행표. **참가 인원에는 안 들어간다** |
| 학생 | `omr.html` | 게이지, 안내 창, 답안지 |

## 40분

관리자가 시작을 누르면 흐르기 시작한다. 멈춤도 되감기도 없다 — 교실의 종과
같다. 늦게 시작했거나 다들 일찍 끝냈으면 관리자가 **시계를 옮긴다**.

| 분 | | 안내 창 |
|---|---|---|
| 0 | **준비령** | 자리에 앉아 기다립니다 |
| 4 | 개별 힌트 공개 | **내 명제 한 줄. 나에게만, 1분만** |
| 5 | **본령** | 자유롭게 이동·대화 |
| 15 / 20 / 25 | **1·2·3차 공통 힌트 공개** | 모두에게 같은 것. 1분 뒤 사라진다 |
| 32 | **착석 안내** | 대화 금지. 답안지가 뜨고 마킹이 열린다 |
| 35 | **종료령** | 마킹이 닫힌다. 그게 곧 제출이다 |
| 36 | 정답 공개 | **1번부터 5초마다 하나씩** |
| 38 | 점수 공개 | 점수 · 등수 · 등급 · 평균 |

게이지는 좌측부터 흐르고, 굵은 단계마다 세모 화살표가 선다. 힌트만 1분
카운트다운을 달고 사라지고, 나머지 멘트는 다음 단계까지 남는다 — 지금 뭘
해야 하는지가 거기 적혀 있기 때문이다.

## 명제

**개별 23개** (★ 17 · ☆ 6) — 한 사람에게 한 줄씩. 사람이 적으면
`P24 → P19 → P08 → P14 → P07 → P22` 순서로 ☆ 부터 뺀다. 17명까지 내려간다.
★ 열일곱만 남아도 공통 힌트와 합치면 해는 하나로 정해진다.

**공통 3개** — 아무에게도 안 나눠 주고 15·20·25분에 모두에게 띄운다.
누구의 패도 죽이지 않으려고 개별 명제에서 아예 뺀 것들이다.
관리자가 판을 열 때 바꿔 넣을 수 있고, 비워 두면 기본값이 나간다.

| | 옛 번호 | 명제 |
|---|---|---|
| C1 | P10 | 홀수 번호 문제의 답은 홀수이다. |
| C2 | — | 답이 5인 문제는 8개이다. |
| C3 | P23 | 답이 4인 문제는 하나도 없다. |

> **C1 하나면 답이 못 박힌다.** 나머지 둘은 그 앞에 있어야 쓸모가 있는데,
> 지금은 C1 이 1차다. 조여드는 맛을 원하면 C1 을 3차로 돌린다.

## 답안지

- 바탕 연노랑, 테두리 짙은 노랑, **우하단이 조금 사선으로 깎여 있다**
- **상단에 바코드** — 굵은 막대가 서너 개씩 뭉쳐 있고 뭉치 사이는 넓다
- 4단 × 10문제 = **40번까지 인쇄된다.** 쓰는 건 1~20번뿐이고, 21~40번은
  흐리게 깔려만 있다. 종이 답안지가 그렇게 생겼다
- 선다 영역 바탕: **1~5·16~20은 연노랑, 6~15는 연분홍.** 문항 번호 칸은 하늘색
- 보기는 세로로 긴 분홍 스타디움, 안쪽은 투명해 바탕색이 비친다.
  탭하면 스타디움보다 조금 넓은 검정이 덮고, 다시 탭하거나 같은 문항의
  다른 보기를 탭하면 풀린다
- **제출 버튼은 없다.** 종료령에 자동 제출된다
- **숨기기**를 누르면 답안지 전체가 뒤집힌다

## 채점

- 한 문제 5점, 20문제 100점
- 정답 공개 때 문항 번호에 빨강 ○ 또는 ✕. 틀린 문제는 정답 보기에 빨강 ○
- 맞힐 때마다 예상점수 옆에 실제 점수가 5점씩 빨강으로 쌓인다
- 등급은 **내신 5등급제** — 10·24·32·24·10%, 누적 10·34·66·90%.
  한 반이 작으면 1등급이 안 나올 수 있다. 21명이면 두 명까지다

## 숨기는 것 셋

1. **내 명제는 나에게만**, 그것도 띄워 두는 1분 동안만 내려간다. 소스를
   열어도 남의 명제는 없다
2. **정답은 종료령까지 안 내려간다.** 그 뒤 열린 것만 하나씩 간다
3. **남의 답안은 끝까지 안 내려간다.** 채점은 서버가 한다
