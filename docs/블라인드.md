# 블라인드 — 플레이 화면

OMR 명제 퀴즈(`omr-quiz/`)를 교실에서 돌릴 때 띄우는 화면이다.
지금은 **화면만** 있다. 서버에 붙이는 일은 다음 단계다.

- 틀: `docs/design/omr.template.html` → `python docs/design/build.py omr omr.html`
- 기획: `플레이 화면(교사용공개용).txt`
- 그림: 실제 OMR 답안지 사진. 괘선 파랑, 보기 분홍 스타디움, 문항칸 하늘색을 거기서 가져왔다

## 두 화면

| | 교사용·공개용 (`omr.html?t=1`) | 학생용 (`omr.html`) |
|---|---|---|
| 시간 게이지 | 큰 글씨 | 있음 |
| 안내 창 | 큰 글씨 | 있음 |
| 진행표 | 전체가 보이고 지금 단계에 ◀ | 없음 |
| 답안지 | 없음 | 착석 안내(32분)부터 |

## 40분

게이지는 좌측부터 흐른다. 세모 화살표는 굵게 적은 것만 세운다.

| 분 | | 안내 창 |
|---|---|---|
| 0 | **준비령** | 자리에 앉아 기다립니다 |
| 4 | 개별 힌트 공개 | 내 명제 한 줄. **1분 뒤 사라진다** |
| 5 | **본령** | 자유롭게 이동·대화 |
| 15 / 20 / 25 | **1·2·3차 공통 힌트 공개** | 1분 뒤 사라진다 |
| 32 | **착석 안내** | 대화 금지, 3분 간 마킹. 답안지가 뜬다 |
| 35 | **종료령** | 자동 제출 |
| 36 | 정답 공개 | 1번부터 5초마다 하나씩 |
| 38 | 점수 공개 | 점수 · 등수 · 등급 · 평균 |

힌트만 1분 카운트다운을 달고 사라진다. 나머지 멘트는 다음 단계까지 남는다 —
지금 뭘 해야 하는지가 거기 적혀 있기 때문이다.

## 답안지

- 바탕 연노랑, 테두리 짙은 노랑, **우하단이 조금 사선으로 깎여 있다**
- **상단에 바코드** — 굵은 막대가 서너 개씩 뭉쳐 있고 뭉치 사이는 넓다
- 4단 × 10문제 = **40번까지 인쇄된다.** 쓰는 건 1~20번뿐이고, 21~40번은
  흐리게 깔려만 있다. 종이 답안지가 그렇게 생겼다
- 선다 영역 바탕: **1~5·16~20은 연노랑, 6~15는 연분홍**
- 문항 번호 칸은 하늘색에 검정 글씨
- 보기는 세로로 긴 분홍 스타디움, 안쪽은 투명해 바탕색이 비친다.
  탭하면 스타디움보다 조금 넓은 검정이 덮고, 다시 탭하거나 같은 문항의
  다른 보기를 탭하면 풀린다
- **제출 버튼은 없다.** 종료령에 자동 제출된다
- **숨기기**를 누르면 답안지 전체가 뒤집힌다

## 채점

- 한 문제 5점, 20문제 100점
- 정답 공개 때 문항 번호에 빨강 ○ 또는 ✕. 틀린 문제는 정답 보기에 빨강 ○
- 맞힐 때마다 예상점수 옆에 실제 점수가 5점씩 빨강으로 쌓인다

## 아직 가짜인 것

서버에 붙일 때 바꾼다.

- **리허설 막대** — 화면 맨 아래. 재생·속도·시간 슬라이더. 붙이면 지운다
- 닉네임, 응시 인원, 날짜, 또래 점수(`CROWD`)
- 개별 힌트는 1판 명제 하나를 박아 뒀다. 1인 1명제로 서버가 나눠 줘야 한다
- **공통 힌트 1·2·3차 내용이 아직 정해지지 않았다.** 지금은 1판 명제를 끼워 뒀다
