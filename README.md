# 미니쇼기 (Mini Shōgi)

3×4 판에서 두는 일본 **동물 쇼기**를 HTML5로 만드는 프로젝트.
한 기기를 가운데 놓고 두 사람이 마주 앉아 둔다.

`index.html`을 브라우저로 열면 곧바로 대국 화면이다. 화면 전체가 판이고, 규칙과 설계 기록은 아래쪽 **규칙** 버튼을 누르면 서랍으로 열린다.

**배치는 화면 비율이 정한다.** 가로가 길면(태블릿을 눕힘) 판을 눕혀 4칸 가로 × 3칸 세로로 놓고 둘이 좌우에 앉는다. 세로가 길면(휴대폰) 판을 세워 3칸 가로 × 4칸 세로로 놓고 위아래에 앉는다. 창을 돌리면 그 자리에서 다시 잡힌다.

대국 화면의 원본은 `docs/design/motion.template.html`이고, 빌드하면 저장소 루트의 `index.html`이 된다:

```
cd docs/design && python build.py motion ../../index.html
```

## 지금까지 정한 것

| 항목 | 결정 |
|------|------|
| 방향 | **A · 나무와 먹** — 오동나무 판, 먹색 손그림, 오각 코마 |
| 프레임 | **P1 정통 오각** (실물 쇼기 코마 실루엣) |
| 이동 표시 | **먹색 점**, 기물을 둘러싼 가상 정사각형의 꼭짓점 4 + 변 중앙 4 |
| 내 코마 | 흰단풍 **가로결** |
| 상대 코마 | 오쿠메 **가로결** |
| 판 | 흰단풍 **세로결** (코마와 결 방향을 직각으로) |
| 진영 | 선공 ↔ 후공. 껍데기와 무관하게 앉은 자리로 부른다 |
| 기물 크기 | 칸의 84%. 병아리 66%, 기린 90%, 닭 95% |
| 배치 | 화면비로 결정. 가로면 4×3 눕힘(좌우 대면), 세로면 3×4 세움(상하 대면) |
| 기물 세트 | **체스(먹선) 한 벌이 기본**. 동물·야수는 숨은 전환으로만 나온다 |
| 상대 | 사람 또는 AI. AI 는 늘 위(가로면 왼쪽) 자리 |
| AI 난이도 | 껍데기가 정한다 — AI 쪽이 야수면 어려움, 아니면 보통 |
| 한 수 제한 | 30초 |

규칙 전문과 확정 사항은 [`docs/rules.md`](docs/rules.md).

### 숨은 전환 (스포일러)

어떤 기물을 **0.6초 안쪽 간격으로 일곱 번 연속** 두드리면 **그 기물 주인 쪽만** 껍데기가 바뀐다. 규칙과 움직임은 그대로다.

| 두드린 것 | 결과 |
|----------|------|
| 킹 · 사자 · 호랑이 ×7 | 그 쪽이 체스 ↔ 동물 |
| 폰 · 병아리 ×7 | 그 쪽이 야수(`pieces-x`) ↔ 직전 껍데기 |

진영별로 따로 논다. 내가 체스인 채로 상대만 야수로 만들 수 있고, **혼자 두기에서 AI 쪽을 야수로 만들면 그때부터 어려움**이다. 난이도 버튼은 따로 두지 않았다 — 험상궂어졌으면 세진 것이다.

전환은 알림으로 말하지 않는다. **그 진영의 기물이 함께 떠올랐다 내려앉고**, 그 꼭대기에서 껍데기가 바뀐다.

### 빌드

```bash
cd docs/design
python build.py motion      # motion.template.html → motion.html

빌드한 뒤에는 페이지를 실제로 한 번 띄워 본다.

```bash
python tools/page-check.py        # index.html 과 admin.html 을 헤드리스로 열어
                                  # 콘솔에 오류가 있으면 실패한다
```

문법 검사만으로는 부족하다. 선언보다 먼저 쓴 const 하나에 스크립트가 통째로
멎어 판도 규칙 창도 안 뜬 채 배포된 적이 있다. 문법은 멀쩡했다.
```

`build.py`가 하는 일은 두 가지다.

1. `[[koma|<기물클래스>|<추가클래스>]]` 를 코마 마크업으로 전개 (이동 방향 점은 기물 종류에서 자동으로 뽑는다)
2. `[[include|<경로>]]` 를 파일 내용 그대로 치환 — `engine.js` 처럼 따로 두고 node 로 테스트하는 코드를 위해서다
3. `ASSET:<경로>` 를 data URI로 치환 — 에셋마다 **한 번만** 등장하도록 CSS 클래스에서 참조하므로 중복되지 않는다

## 프로토타입에 들어간 것

**착수** — 기물을 탭하면 갈 수 있는 칸에 붉은 반투명 원이 뜬다. 원을 탭하면 들어 올려 호를 그리며 내려앉는다. 끌어서 옮길 수도 있고, 끄는 동안에는 그 기물이 맨 위로 떠서 그림자가 진다.

**소리** — 오디오 파일 없이 Web Audio로 합성한다.
- 탁: 삼각파 185Hz + 사인 460Hz의 빠른 감쇠(나무 몸통) + 2kHz 대역통과 노이즈 30ms(부딪는 순간). 칠 때마다 음정 ±6% 변조
- 초읽기: 남은 5초부터 1초마다 딸깍

**잡기** — 잡힌 기물을 먼저 들어내 손패로 보낸 뒤, 잡은 기물이 빈 칸에 내려앉는다.

**판정** — 캐치, 트라이, 스테일메이트, 3회 반복 무승부, 시간 초과.

**AI** — `engine.js` 의 알파베타 탐색이 워커에서 돈다(`ENGINE.toString()` 을 Blob 으로 말아 띄우므로 파일이 늘지 않는다). 워커를 못 띄우거나 답이 없으면 메인 스레드로 넘어간다.

- 보통: 220ms 예산. 최선수만 고집하지 않고 110점 안쪽의 수 중에서 고른다 — 다만 이기는 수를 버리거나 곧장 지는 수를 고르지는 않는다
- 어려움: 900ms 예산, 최선수만
- AI 차례에는 시계를 재지 않는다. 답이 빨리 나와도 380ms 는 붙잡아 둔다
- 실제 대국에서 이미 두 번 나온 국면은 무승부로 보게 넘겨준다 — 안 그러면 같은 자리를 맴돈다

## 온라인 대전

한 기기에 마주 앉는 대신 각자 기기에서 둔다. 서버가 **심판**이다 —
클라이언트가 보낸 수는 제안일 뿐이고, 판은 서버의 `engine.js` 가 직접 굴린다.
규칙이 두 벌로 갈라지지 않도록 **클라이언트와 서버가 같은 파일을 쓴다**.

| | |
|---|---|
| 들어가는 길 | **대국 목록**. 열린 대국을 보고 고르거나 직접 연다 |
| 대국 상태 | 대기(닉네임) / 대국 중(닉네임 vs 닉네임) |
| 공개 · 비공개 | 기본은 공개. 비공개는 **숫자 네 자리** 비밀번호 (가리지 않는다) |
| 닉네임 | pid 에서 기계적으로 뽑는다. 고를 수 없고, 같은 사람은 늘 같은 이름 |
| 연승 뱃지 | 2연승 남색 · 5연승 크림슨 · 10연승 금색(번쩍) |
| 시계 | 한 수 30초. **서버가 갖는다**. 둘이 앉기 전에는 돌지 않는다 |
| 종료 | 캐치 · 트라이 · 스테일메이트 · 3회 반복 · 시간 초과 · 나감 · 중단 |
| 나가기 | 두던 중이면 **패**. 연승도 깨진다 |
| 끊김 | 패가 아니다. 45초 기다렸다 중단. **연달아 3회면 연승은 인정하지 않는다** |
| 대국의 수명 | 한 판 끝나도 닫히지 않는다. 둘 다 나가야 목록에서 사라진다 |
| 시점 | 판을 눕히지 않고 **내 자리가 늘 아래**로 오게 뒤집는다 |
| 기록 | 끝난 판의 승패만 Neon 에 남는다. 중단된 판은 남기지 않는다 |
| AI | 서버는 탐색하지 않는다. 혼자 두기는 그대로 클라이언트 워커 |

### 어디에 붙는가

클라이언트는 기본적으로 `wss://mini-shogi.onrender.com/ws` 를 본다.
로컬에서는 `ws://<호스트>:3000/ws` 로 간다. 둘 다 아닐 때는 주소 뒤에 붙인다:

```
index.html?server=ws://127.0.0.1:3001/ws
```

`DATABASE_URL` 은 `server/.env` 에 둔다(`\.env.example` 참고). **커밋하지 않는다.**
없으면 기보만 안 남고 대국은 그대로 된다.

### 배포

`render.yaml` 이 블루프린트다. Render 무료 인스턴스는 **15분 무입력이면 잠들고
깨는 데 1분쯤** 걸리므로 밖에서 `/healthz` 를 주기적으로 두드려 깨워 둔다.
상시 가동은 월 744시간이라 무료 750시간을 거의 다 쓴다 — 그 워크스페이스에
다른 무료 서비스는 올리지 않는 편이 좋다.

## 한글 퀴즈

같은 서버, 같은 관리자 화면에 **대국이 아닌 판**이 하나 더 붙는다. 찢긴
글자를 팀으로 맞힌다. 19~24명을 3명씩(남으면 4명) 무작위로 묶고, 정해진
23개 낱말을 순서대로 낸다. **점수는 시간이다** — 문제가 뜬 뒤 흐른 초를
그대로 받고, 오답은 20초를 깎는다.

| | |
|---|---|
| 관리자 | `admin.html` — 대회와 같은 자리에서 열고, 팀 짜고, 넘기고, 닫는다 |
| 학생 | `quiz.html` — 목록에서 고르고 비번 넣으면 대기. 닉네임은 쇼기와 같은 것 |
| 문제 | `docs/문제.txt` 에 적힌 순서대로 23개 |
| 글자 | 14x14 점판. 셋으로 찢어 **한 장씩만** 4초마다 보여 준다 |
| 공개 | 성한 글씨를 붉게 2초, 그 뒤 세 낱장을 0.5초마다 5초간 |

규칙 전문과 정한 까닭은 [`docs/퀴즈.md`](docs/퀴즈.md).

```bash
python tools/glyphs.py        # docs/문제.txt 를 고쳤으면 다시 찍는다
python docs/design/build.py quiz ../../quiz.html
```

`server/glyphs.js` 와 `server/dots.js` 가 `shared/` 가 아닌 것은 일부러다.
답도 낱장 셋도 화면으로 내려가지 않아야 한다.

### 관리자 비밀번호

박아 둔 scrypt 해시가 기본이다. `server/.env` 에 `ADMIN_PW` 를 넣으면
그것이 비밀번호가 된다 — 해시를 다시 굽지 않고 바꾸고 싶을 때와, 소켓
검사가 들어올 때 쓴다. 저장소에는 값이 없고, Render 대시보드에 넣지
않으면 박아 둔 해시가 그대로 쓰인다.
